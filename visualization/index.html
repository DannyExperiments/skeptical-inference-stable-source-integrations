Why a blocked repair matters

Each old formula f becomes q ∨ f. A reliable q marker gives a jointly consistent first tier that includes every guarded formula. A reliable ¬q marker instead recovers the old formulas.

Within that false-marker branch, each successful repair eliminates both bad maxcon candidates by adding a middle-tier formula. A missing repair lets them survive and induce a different partition. For the blocked example, y = t = 0 defeats every outer choice, so only the true-marker order remains stable.
